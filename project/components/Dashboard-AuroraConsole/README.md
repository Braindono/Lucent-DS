# Dashboard — Aurora Console

A full application screen in Concept C's language — "a Kibana crossed with a Kanban board, from the future" — built to show several information designs living together on one set of tokens: stat tiles with sparklines, a stacked-area time series, a categorical bar chart, a sequential heatmap, a radial gauge, a Kanban board and a log stream. Chart marks use `viz-series-a/b/c`, never the raw hue swatches or a concept accent directly; status and priority everywhere — the gauge's severity band, the Kanban priority chips, the log stream's status dots — use `status-good/warning/serious/critical`, always paired with a shape or a label, never color alone. The categorical and status colors here were run through the dataviz skill's validator against Lucent's own light and dark chart surfaces, not eyeballed; see the usage notes on those tokens in `tokens.json` for the numbers. Density is intentional — this is Concept C's "judge it on whether it stays legible" case, not its restraint.

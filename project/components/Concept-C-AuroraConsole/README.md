# Concept C — Aurora Console

The maximalist end: a retro-futurist control console, not a flat app screen. Layer glass densely — a `glass-surface-strong` shell at `glass-elevation-3` can hold nested dials, pills and readouts, each with its own depth. Draw on both `accent-b` and `accent-c` together (this is the one concept allowed two accents at once); use `accent-c-glow` only in `box-shadow`/`filter` glow effects, never as a solid text or icon color — solid marks stay on `accent-c`, `accent-b` or `ink`. Radii run large: `radius-lg`/`radius-xl` for shells, `radius-full` for every dial, pill and badge — nothing sharp here. `display-xl`/`display-lg` in `data-mono` carry the big numeric readouts; a segmented level-meter or dial cluster is this concept's signature texture, built from the `space-*` grid the same way Concept A's tick marks are, just denser and in color. Judge density by whether it stays legible, not by how restrained it is — restraint is Concept A's job.

# Concept A — Instrument

The brutalist end of the system: a control panel, not a screen. Build every surface from `surface-raised`/`surface-sunken` with `shadow.neu-raised`/`neu-inset` — never a second fill color for elevation. Spend `accent-a` on exactly one element per view, usually the primary action; everything else stays neutral (`ink`, `ink-muted`, `ink-700` for structural rules). Use `radius-xs`/`radius-sm` throughout — nothing rounder. Set every readout and tick label in `data-mono`/`label-mono`, uppercase where it's a tag. Glass appears once, as a small `glass-surface` chip, to prove the hybrid without softening the panel; if a layout needs more than one glass element, it has drifted toward Concept B. Lay controls on the `space-*` grid with visible alignment — this concept is the one place a thin `ink-700` guide line or tick mark is welcome.

# Concept B — Atrium

The balanced middle, closest to a current iOS/macOS glass language pushed further. Anchor every composition on one neumorphic base (`surface-raised` + `shadow.neu-raised`), then float one or two `glass-surface`/`glass-surface-strong` panels above it at `glass-elevation-2`/`3` with `backdrop-filter: blur(blur-sm/md)`, a `glass-border` on the top and left edge, and a `glass-highlight` line tracing that edge. Give each floating plane its own parallax depth — the nearer the plane, the more it should shift against pointer or scroll movement, never the whole composition moving as one flat layer. Use `radius-md`/`radius-lg` throughout; nothing as sharp as Concept A, nothing as round as Concept C. `accent-b` (cyan) carries the primary action and active toggle states; a low-opacity `accent-b` glow (`opacity-glass-subtle`) behind the glass is the one atmospheric touch this concept allows — keep it to a single soft wash, never a second color layered in.
